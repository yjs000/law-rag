# B-017 반복 검토 기록

- `raw/`: 날짜별 원자료. API 응답이나 DB에서 확인한 관찰을 출처·시각과 함께 보존한다. 개인 사건자료와 인증정보는 넣지 않는다.
- `rounds/YYYY-MM-DD-<회차이름>.json`: 그 회차의 사례별 문제, 근거, 사람 판정과 미확인 항목. 같은 날에도 새 회차 이름을 써서 기존 기록을 덮어쓰지 않는다. 같은 질문의 여러 실행은 반복 횟수로 따로 센다.
- `review.json`: 모든 회차를 읽는 누적 결론. 반복 문제, 범위 판단의 이유, 다음 회차 항목만 모은다.

다음 회차에는 (1) 원자료 출처·코드 버전·실행 조건·질문·응답·시각을 기록하고, (2) 회차 판정에서 결론, 쉬운 이유, 다음 행동, 인용 연결과 화면 순서를 사람이 확인하고, (3) `review.json`에 새롭거나 달라진 판단만 반영한다. 모델 출력이 달라질 수 있으므로 재시도 횟수와 같은 질문의 반복을 남긴다. 확인하지 않은 법적 정확성·웹 화면·사용자 만족은 `미판정`으로 둔다.

기존 2026-10-21 원자료는 전체 API 응답이며, 2026-10-27 원자료는 DB의 저장 응답에서 뽑은 관찰 요약이다. 두 자료의 상세 수준이 다르므로 2026-10-27 인용 원문과 전체 응답은 이 폴더만으로 재검증할 수 없다.
