# 오늘 읽는 law-rag 학습 코스

이 폴더는 구현 순서대로 쌓인 작업 일지가 아니라, 현재 프로젝트를 처음 이해하는 사람을 위한 한 번의
읽기 코스다. 과거 실험의 세부 명령과 수치는 권위 설계 문서·완료 실행 계획·생성 결과에 남기고,
여기서는 지금도 유효한 개념과 선택 이유만 설명한다.

## 독서 계획

선택 실습을 제외한 본문은 약 2시간 분량이다. 오늘 처음 읽는다면 아래 순서를 그대로 따른다.

| 순서 | 장 | 읽고 나면 답할 수 있는 질문 | 예상 시간 |
|---:|---|---|---:|
| 1 | [시스템 지도와 실행 경계](01-system-map.md) | Web·API·collector는 왜 나뉘고 어디에서 실행되는가? | 15분 |
| 2 | [법령 코퍼스의 생애주기](02-corpus-lifecycle.md) | 공식 원문이 어떻게 버전·조문·벡터로 안전하게 바뀌는가? | 25분 |
| 3 | [근거 우선 검색과 답변](03-evidence-first-retrieval.md) | 질문이 어떤 검색 경로를 거쳐 인용 가능한 답이 되는가? | 30분 |
| 4 | [평가와 실험 읽기](04-evaluation.md) | 검색 품질을 무엇으로 재고, 아직 어떤 결과가 없는가? | 25분 |
| 5 | [사용자·개인정보·장애 안전](05-product-safety.md) | 로그인·이력·AI 장애·취소를 어떻게 안전하게 처리하는가? | 25분 |
| 6 | [v1→LangChain/LangGraph/LlamaIndex 진화](06-v1-to-langchain-evolution.md) | v1·v2·v3가 왜 병행 존재하고, 각 단계에서 뭘 새로 짜고 뭘 재사용했는가? | 15분 |

한 장을 읽은 뒤 `핵심 확인` 세 문장에 스스로 답할 수 있으면 다음 장으로 넘어간다. `직접 확인` 명령은
선택 사항이다. 오늘은 먼저 전체 지도를 완독하고, 필요한 장의 실습만 나중에 실행해도 된다.

## 읽을 때 지킬 구분

- **현재 동작**은 코드와 승인된 설계에 반영된 계약이다.
- **보류**는 아이디어나 물리 자산이 있어도 현재 검색·평가 경로에는 쓰지 않는다는 뜻이다.
- **제외**는 현재뿐 아니라 후속 설계·도입 후보에도 넣지 않는다는 뜻이다. HNSW가 여기에 해당한다.
- **미검증**은 구현이 있어도 실제 운영 데이터나 승인 gold로 품질을 증명하지 않았다는 뜻이다.
- 학습 문서와 코드가 다르면 [아키텍처](../../ARCHITECTURE.md), 관련 제품 명세와 설계 문서를 우선하고
  같은 변경에서 이 코스를 고친다.
