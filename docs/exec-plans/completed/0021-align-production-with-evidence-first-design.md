# 실행 계획 0021: 프로덕션을 근거 우선 실험 설계와 정렬

상태: 완료
작성일: 2026-08-03
소유자: Codex

## 목적과 사용자 결과

실험 A~D에서 확인한 `corpus 정확성 → 법률 계층 복원 → 후보 검색 → 조 단위 중복 제거 → 직접 근거만 생성에 사용` 순서를 프로덕션 코드에 반영한다. 임베딩이 있을 때 자동으로 lexical 결과와 결합하던 hybrid/RRF 경로는 사용하지 않고, dense-only 결과가 없을 때만 독립적인 키워드 안전 폴백을 실행한다.

## 범위와 비범위

범위:

- collector 활성화 전에 실험 C와 같은 법률 계층·본문 불변조건 검증
- 직접 조문 검색 선행 유지
- 자연어 임베딩 검색을 dense-only로 분리하고 hybrid/RRF 자동 결합 제거
- dense 결과가 0건일 때만 기존 4단계 키워드 검색 실행
- 같은 문서의 같은 조문이 후보를 중복 점유하지 않도록 조 단위 중복 제거
- 생성 문맥을 순위가 높은 최대 5개 조문으로 제한
- 검색 trace와 설계·학습 문서를 실제 동작에 맞게 갱신

비범위:

- RRF, BM25, 별도 reranker 또는 similarity cutoff 도입
- 고정 `required_evidence_terms`를 프로덕션 질문 판정에 사용
- 임의 질문의 의미 기반 충분성을 판정하는 새 LLM judge 도입
- 운영 DB 마이그레이션 또는 임베딩 backfill 실행
- 기존 사용자의 실험 B 실행 결과 수정

## 측정 가능한 완료 조건

- 구조 표지가 조문 본문을 대체하거나 부모가 없고 조문을 가로지르는 경로는 저장 전에 실패한다.
- 임베딩이 있는 자연어 검색은 lexical 점수와 결합하지 않은 dense-only SQL을 한 번 실행한다.
- dense 후보가 있으면 키워드 SQL을 실행하지 않는다.
- dense 후보가 0건이면 기존 4단계 키워드 검색으로 안전하게 폴백한다.
- 자연어 검색 결과에는 문서·조문 조합당 최고 점수 청크 하나만 남는다.
- 생성 모델에는 순위가 높은 서로 다른 조문 최대 5개와 문자 예산 이내의 원문만 전달된다.
- Evidence Recall과 고정 근거 계약은 오프라인 실험에만 남는다.
- 관련 단위·통합 테스트, Ruff와 문서 검사가 통과한다.

## 검증 및 롤백

우선 API·collector의 관련 테스트와 Ruff를 실행하고 이후 문서 검사와 저장소 대표 검증을 실행한다. 검색 변경은 DB 데이터를 수정하지 않는다. 회귀가 있으면 dense-only 분기와 조 단위 중복 제거를 되돌려 기존 키워드 전용 경로를 유지할 수 있다. validator 강화로 기존 원문이 거부되면 오류 원문을 보존한 상태에서 파서 또는 검증 규칙의 어느 쪽이 계약을 어겼는지 먼저 확인한다.

## 결정 로그

- 2026-08-03: 현재 운영 corpus의 임베딩이 0개인 사실과 별개로, 코드에 남은 잠재 hybrid/RRF 실행을 제거한다.
- 2026-08-03: 임베딩 검색은 dense-only 기준선을 유지하고 결과가 전혀 없을 때만 키워드 안전 폴백을 사용한다. 두 순위를 결합하지 않는다.
- 2026-08-03: 고정 evidence contract와 Evidence Recall은 오프라인 평가 장치로 유지하고 프로덕션 요청 처리에 연결하지 않는다.

- 2026-08-03: collector 활성화 validator에는 실험 C의 부모 경로·조문 루트·구조 표지 검사가 빠져 있음을 확인했다.

- 2026-08-03: 생성 문맥 선택은 문자 예산만 적용하며 조 단위 중복 제한이 없음을 확인했다.
- 2026-08-03: 활성화 validator에 조문 루트, 구조 표지, 부모 존재, 조문 경계 검사를 추가하고 collector 테스트 37개를 통과했다.
- 2026-08-03: 런타임의 `hybrid_search` 호출을 제거하고 dense-only 성공과 dense 0건 키워드 폴백을 별도 SQL·trace로 구현했다.
- 2026-08-03: 메모리·Postgres 후보와 생성 문맥에 조 단위 중복 제거를 적용하고 생성 문맥을 최대 5개 조문으로 제한했다.

## 완료 결과

- corpus가 장·절 구조 표지를 조문 본문으로 활성화하거나 끊어진 부모 경로를 가진 경우 임베딩 전에 실패한다.
- 임베딩 검색은 키워드 순위와 결합되지 않는다. dense 후보가 있으면 `dense_only`, 0개일 때만 `dense_then_keyword_fallback`을 기록한다.
- 같은 법률 조문의 하위 청크는 최고 순위 하나만 검색 후보로 남고, 생성에는 서로 다른 조문 최대 5개만 전달된다.
- Evidence Recall과 고정 필수 문구는 오프라인 평가 전용이며 프로덕션 정답 판정 단계로 추가하지 않았다.

## 미결정과 차단 요소

- 임의 자연어 질문의 근거 충분성은 아직 범용 평가셋과 검증된 selector가 없다. 이번 변경은 검색 점수를 정답 판정으로 사용하지 않고, 기존 생성 후 인용 게이트를 유지한다.
- dense와 키워드 결합은 더 넓은 gold 평가셋에서 Evidence Recall·MRR·Evidence Precision 개선을 증명할 때 별도 계획으로 검토한다.
