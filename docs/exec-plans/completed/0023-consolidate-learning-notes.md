# 학습 노트 통합 실행 계획

상태: 완료
시작일: 2026-08-04

## 목적과 사용자 결과

아직 학습 노트를 읽지 않은 사용자가 `docs/learning` 전체를 오늘 한 번에 읽고 프로젝트의 현재 구조와
안전 경계를 이해할 수 있게 한다. 작성 순서대로 쌓인 42개 본문을 현재 상태 기준의 5개 장으로 합치고,
과거 실험의 세부 실행 기록은 권위 설계·완료 계획·생성 결과로 연결한다.

## 범위와 비범위

- 범위: `docs/learning` 전체 재구성, 깨지는 저장소 내부 링크 갱신, 독서량·링크·현재 계약 검증
- 비범위: 애플리케이션 코드와 제품 동작, 새 아키텍처 결정, 외부 조사, 배포와 푸시
- 보존: 질문은행 승인과 HNSW 정책 변경은 앞선 기능별 커밋으로 분리하고 이 커밋에 섞지 않는다.

## 측정 가능한 완료 조건

- `docs/learning/index.md`에서 순서대로 읽을 본문이 5개 이하이다.
- 전체 본문은 8,000어절 이하이고 예상 독서 시간은 2시간 이내이다.
- 수집·검색·평가·인증/안전처럼 겹치던 개념은 각각 한 장에서만 본문으로 설명한다.
- 현재 계약인 dense-only, 독립 keyword fallback, parser v3, corpus 준비 게이트, 승인 gold 미실행 상태를
  과거 구현과 혼동하지 않는다.
- 저장소 내부 Markdown 링크가 모두 존재한다.
- 학습 문서와 링크 갱신만 커밋한다.

## 검증 및 롤백

- PowerShell로 Markdown 상대 링크를 해석해 누락 파일을 검사한다.
- `rg`로 제거한 파일명과 폐기된 현재형 설명(`hybrid`, RRF, HNSW 활성)을 검사한다.
- 어절·줄·파일 수를 집계하고 `git diff --check`, `git diff --stat`, `git status`로 범위를 확인한다.
- 문서 전용 변경이므로 제품 테스트는 실행하지 않는다. 문제가 있으면 커밋을 되돌리거나 Git에서 제거된
  원본을 복구할 수 있다.
