# 답변의 결론 우선·쉬운 말·근거 표시 개선

## 목적과 완료 조건

B-017은 **근거가 확보된 답변을 일반인이 바로 이해하고, 필요하면 근거를 확인할 수 있게 보여주는 작업**이다. 검색·대화 상태·법적 수치의 정확성 문제를 답변 문구로 가리지 않는다. 기존 F-010 프롬프트 완료 판정과 별개로 실제 출력과 웹 화면을 사람이 검토한다.

1. **결론** — 첫 문장에서 질문에 직접 답한다. 현재 근거와 사실로 판단할 수 없다면 부족한 정보를 쉬운 말로 밝히며 임의 규정을 고르지 않는다.
2. **쉬운 이유와 다음 행동** — 결론 다음에 이유와 사용자가 할 일을 보여준다. 처음 등장한 법률 용어와 `NFTC`·`NFPC` 같은 약어에는 쉬운 뜻을 붙인다. 근거가 있어도 설명 본문이 비고 일반적인 체크리스트만 남는 경우는 실패로 판정한다.
3. **검증 가능한 근거** — `C1` 같은 내부 식별자는 사용자 문장에 쓰지 않는다. 주장별 인용 링크와 원문·버전·한계는 보존한다.
4. **화면 순서** — 결론 → 쉬운 이유 → 다음 행동 → 확인 가능한 근거·한계 순서로 읽힌다. 근거를 숨겨 검증을 어렵게 만들지 않는다.
5. **사람 판정** — B-017에 해당하는 대표 질문의 변경 전후 실제 답변과 화면을 사람이 비교한다. 위 네 항목이 납득할 만할 때까지 미달 사례만 반복 수정한다. 구조 테스트 통과만으로 완료하지 않는다.

## 표본과 책임 경계

`apps/api/evaluation/b017/`의 7개 질문·9개 성공 답변은 **전체 관찰 목록**이다. 전부 B-017 평가 대상이라는 뜻은 아니다. 2026-10-27의 성공 답변 4건은 같은 질문의 반복이므로 독립 질문 4개로 세지 않는다.
