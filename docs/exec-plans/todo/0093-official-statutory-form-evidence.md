# 공식 별지 서식을 답변 근거로 수록

B-020의 허가·변경허가 사례에서 참조하는 별지 경로가 개발 DB에서 반환되지 않았고, 현행 법령 파서에 별지 서식 추출 경로가 없다. 제4조의 이미 색인된 첨부서류 각 호는 B-020 검색 범위다.

1. 공식 Open API의 해당 버전 응답에서 별지 식별자, 제목, 원문 또는 첨부 링크 제공 여부를 확인한다. 결과는 제공 가능 범위와 출처·버전 매핑이다.
2. 구조화된 원문을 제공할 때만 JSON 우선·XML 폴백 계약과 정상·누락·다른 버전 회귀를 확정하고, 최소 파서·수록 경로를 구현한다. 공식 API가 링크만 제공하면 그 한계를 기록하고 사용 가능한 근거로 서식명·공식 위치를 안내하는 경계를 확정한다.
3. 개발 환경에서 수록·색인 여부와 B-020 두 질문의 인용을 검증한다. 외부 호출 및 개발 DB 쓰기 대상과 범위는 실행 전에 명시한다.

## 공식 API 확인 결과

전기사업법 시행규칙 MST 291405의 JSON 상세에서 별지 제1호 전기사업 허가신청서와 제3호 사업허가 변경신청서에 구조화된 별표내용이 반환됐다. 번호 0001과 0003을 공유하는 일반 별표가 있으므로 번호만으로 키를 만들면 충돌한다. 다음 구현은 실제 응답의 종류·식별 필드를 확인하고 버전별 경로를 정한 후 JSON·XML 파서 회귀를 추가한다. API 상세에서 확인한 구조화 텍스트를 사용한다.
