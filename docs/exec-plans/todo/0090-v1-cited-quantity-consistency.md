# V1 인용 수치와 체크리스트 수치 불일치 검증

## 문제와 판정

2026-10-21 실제 응답의 요약과 C5 원문은 `3천킬로와트`인데 체크리스트 예시는 `3kW 이하 여부`다. 숫자 단위가 붙은 잘못된 예시가 같은 C5 인용을 달고 사용자에게 전달됐다. `validate_draft`는 현재 인용 ID와 섹션·체크리스트 구조만 확인한다. 숫자 대조 보조 함수는 있지만 검증 경로에서 호출되지 않는다. 이는 B-017의 문장·화면 개선과 분리한 내용 정확성 버그다.

기존 E-001은 평가 작업이고, TD-005는 과거 완료 기록이다. 현행 구조 검사는 과거 의미 검사 오탐을 줄이기 위해 의도적으로 채택됐다. 따라서 과거의 광범위한 단어 중첩 검사를 그대로 되살리지 않고, 근거에 없는 수치·단위 조합을 막는 좁은 계약을 검토한다. 요약의 `3천킬로와트`가 C5 수치와 일치한다는 확인은 체크리스트 오류 판정에 한정한다. 다른 법률 해석의 정확성은 여기서 단정하지 않는다.
