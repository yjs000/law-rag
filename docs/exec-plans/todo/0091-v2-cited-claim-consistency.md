# V2 답변의 인용 근거와 적용 대상·수치 불일치

## 재현 증거

[B-017 최신 V2 재판정](../../../apps/api/evaluation/b017/rounds/local-v2-recheck-aa64e51.json)에서 인용 링크가 유효해도 다음 두 주장이 사용자에게 전달됐다.

- 소규모 태양광 설비 답변이 신고만으로 충분하다고 단정했다. 연결된 C2는 태양광 설비를 제외한다.
- 사업개시신고 서류 답변이 관할 기준을 3 kW로 표시했다. 연결된 C2는 3천 kW라고 적고 있다.

## 목표와 범위

두 재현 사례가 V2 게시 전에 차단되거나 근거가 확인된 안내로 안전하게 바뀌는 것을 확인한다. 적용 대상과 숫자·단위가 일치하는 답변은 통과해야 한다. 검색 재설계와 범용 법률 해석은 범위에서 제외한다. [B-018](0090-v1-cited-quantity-consistency.md)은 V1 체크리스트의 수치 검증을 담당한다. 구현 경로와 구체적인 회귀 계약은 착수 시 확정한다.
