## 문제와 완료 조건

사용자는 조문 번호와 `NF…` 같은 표기가 많고 결론이 늦어 초등학생이 이해하기 어렵다고 보고했다. `NF…`의 실제 출처는 응답 표본에서 확인한다. 기존 F-010 프롬프트 완료 판정과 별개로 실제 화면과 출력의 품질을 검증한다.

- 첫 문장에서 질문에 직접 답하거나 근거 부족을 쉬운 말로 밝힌다. 적용 요건이 빠지면 단정하지 않고 필요한 사실을 먼저 묻는다.
- 쉬운 이유와 다음 행동을 결론 다음에 보여준다. 조문·원문·인용은 사용자가 검증할 수 있게 보존하되 본문 읽기를 방해하지 않게 배치한다.
- 내부 식별자와 설명 없는 전문용어를 사용자 문장에 노출하지 않는다. 법률 주장과 인용의 연결은 유지한다.
- 같은 대표 질문의 변경 전후 실제 출력을 사람이 비교하고, 근거 없는 주장·누락된 인용이 없는지 확인한다.
