# 0044: 공급자 중립 답변 모델 선택 계약

상태: `제안됨 (2026-08-09)`

제안 출처: 사용자가 현재 내부 API 식별자 `terra`를 호환성 때문에 즉시 제거하지는 않되,
추후 특정 Codex 모델명에 고정하지 않고 여러 답변 provider·model을 설정으로 바꿔 끼울 수
있는 구조로 전환하도록 TODO 등록을 지시했다.

## 목표

- 공개 요청 계약의 `answer_mode="terra"`를 공급자 중립적인 AI 답변 의도로 대체한다.
- 실제 provider와 model은 서버 설정 또는 허용된 모델 프로필에서 선택하며 Web copy와 요청
  스키마가 특정 제품명에 의존하지 않게 한다.
- 기존 저장 질문과 클라이언트가 보내는 `terra` 값은 명시적인 호환 계층에서 읽을 수 있게
  유지하고, 마이그레이션 기간과 제거 조건을 기록한다.

## 포함 범위

- 요청·응답 스키마의 공급자 중립 필드명과 허용값 설계
- Web 선택값, 저장된 질문·대화 이력, API 라우팅의 단계적 마이그레이션
- provider/model registry 또는 설정 프로필과 가용성·fallback 상태 계약
- 기존 `terra` 입력에 대한 역호환 테스트와 제거 가능 시점의 telemetry 기준
- 제품 명세·설계 문서·OpenAPI 예시의 용어 정리

## 비범위

- 이번 0036 UI copy 수정에서 내부 `terra` 값을 즉시 제거하는 변경
- 검증되지 않은 모델을 production 기본값이나 자동 fallback으로 추가하는 변경
- 모델별 법률 정확성·개인정보·비용 검증을 건너뛰는 동적 전환

## 완료 조건

- 특정 provider/model을 설정만으로 교체해도 Web 요청과 저장 이력 계약이 유지된다.
- 기존 `terra` 요청 및 저장 데이터가 호환 계층을 통해 동일한 AI 답변 의도로 해석된다.
- 허용되지 않거나 사용할 수 없는 모델은 검색 전용으로 안전하게 전환되고 이유가 공급자
  중립 코드로 기록된다.
- 정상·호환·미지원·provider 장애 경로의 API/Web 회귀 테스트가 통과한다.

## 승격 조건

- 사용할 provider/model 프로필 목록과 공개 선택 범위를 사용자가 확정한다.
- 저장 데이터 및 공개 API 호환 마이그레이션 설계가 승인된다.
