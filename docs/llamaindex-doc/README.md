# LlamaIndex 문서 한국어 번역

LlamaIndex 공식 Python 문서 중 **Agent Workflows 전체 섹션**, 요청한 Workflow 예제, 앞서 제공된 agent 문서를 Markdown으로 번역한 자료입니다. 제목과 본문은 한국어로, 전문 용어·API 식별자·코드 예제는 영어 원문으로 유지했습니다.

## 빠른 길잡이

| 목적 | 시작할 문서 |
| --- | --- |
| Workflow 전체 구조와 하위 페이지 탐색 | [Agent Workflows 색인](workflows/README.md) |
| 기초부터 상태·동시성·실행·배포 순으로 학습 | [Workflow 소개](workflows/introduction.md) |
| 요청한 실습 예제 탐색 | [Workflow 예제 색인](examples/README.md) |
| Agent, state, 사람 개입 문서 탐색 | [Agent 문서 색인](agents/README.md) |

## 추천 읽기 순서

1. [Workflow 소개](workflows/introduction.md)에서 `Workflow`, `step`, event 모델을 봅니다.
2. [분기와 반복](workflows/branches-and-loops.md), [동시 실행](workflows/concurrent-execution.md), [비동기 Workflow](workflows/async-workflows.md)를 읽습니다.
3. [이벤트 스트리밍](workflows/streaming.md), [상태 관리](workflows/managing-state.md), [Resource 객체](workflows/resources.md)를 살펴봅니다.
4. [오류 처리](workflows/error-handling.md), [사람 개입](workflows/human-in-the-loop.md), [내구성 있는 Workflow](workflows/durable-workflows.md)를 읽습니다.
5. [테스트](workflows/testing-workflows.md), [관측 가능성](workflows/observability.md), [서버 실행](workflows/workflow-server.md), [Python Client](workflows/python-client.md)를 확인합니다.
6. 실제 적용은 [예제 색인](examples/README.md)에서 목적에 맞는 페이지를 선택합니다.
