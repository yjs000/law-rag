# V2 공개 요약 전체의 쉬운 말

2026-11-06 사용자가 설계를 승인했다. 이 변경은 B-017의 후속 B-023이다.

## 범위와 결정

V2 `core`가 만드는 공개 `summary`의 모든 문장에 짧은 안내체를 요청한다. 적용 대상, 의무·권고의 강도, 조건·예외, 기관은 원문 범위 안에서 보존한다. 모델에 문체만 지시한 두 안에서는 “하려는 자”가 6회 모두 남았다. 새 모델 호출을 더하면 비용과 응답 시간이 늘고 재작성의 의미 보존도 별도로 확인해야 한다. 기존 생성 단계에 문체 예시를 넣고 의미가 분명한 의무 문형만 근거 검사 전에 바꾸는 안을 선택한다.

일반 법률 답변에서 인용문이나 여러 절을 포함하지 않는 단순 의무 문장의 “하려는 자는 …야 한다”와 같은 문형을 “하려면 …야 합니다”로 표현한다. 맞는 문형은 요약의 모든 문장에서 확인한다. 이미 쉬운 문장, 인용문, 문형이 모호한 문장, 추가 정보 요청과 근거 부족 답변은 원래 표현을 보존한다. 인용 ID, 공개 인용, action, 응답 스키마와 기존 근거 검사 및 복구 경로를 보존한다. 단순 문형 외의 쉬운 말 준수는 모델 지침에 따른다.

## 확인한 결과

2026-11-06 로컬 V2의 `/v2/question-executions/{id}/core`와 `/{id}/finalize`로 전기사업법 제7조 제1항 허가 질문을 실행했다. 저장소에 보관된 공개 법령 인용 한 건으로 준비된 실행 상태를 메모리에 구성했다. NVIDIA NIM의 기존 모델로 후보를 3회 실행했고 모두 “전기사업을 하려면 기후에너지환경부장관 또는 시·도지사의 허가를 받아야 합니다.”가 요약과 최종 답변에 표시됐다. 두 단계의 인용이 같았고 기존 근거 검사를 통과했다. 실험은 질문 한 건을 반복한 결과다. 다문장 요약, 인용문과 다른 적용 대상은 오프라인 회귀에서 검증한다.
